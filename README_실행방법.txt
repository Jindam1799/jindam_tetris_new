진담 HSK 테트리스 — 실행 방법
==============================
© 2026 진담중국어. All rights reserved.
게임 코드·디자인·아이콘·짝꿍어휘 자료의 저작권은 진담중국어에 있으며, 무단 복제·배포를 금지합니다.


■ Windows
  1) 「바탕화면 바로가기 만들기(Windows).bat」을 한 번 더블클릭하세요.
     → 바탕화면에 아이콘이 생기고, 앞으로는 그 아이콘으로 항상 Chrome에서 열려요.
  2) 바로 해 보고 싶으면 「게임시작(Windows).bat」을 더블클릭해도 돼요.
  ※ "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요.

■ Mac
  「게임시작(Mac).command」를 더블클릭하세요.
  ※ 처음에 막히면 파일을 마우스 오른쪽 클릭 → [열기]를 누르세요.
  ※ Mac에서는 중국어 음성으로 Tingting이 자동으로 쓰여요.

■ 휴대폰 · 태블릿
  - 화면 아래 버튼: 위쪽 = 돌리기 / 왼쪽·오른쪽 = 옮기기 / 아래쪽 = 내리기 / 드롭 = 바로 떨어뜨리기
  - 보드 위 손가락 조작: 탭 = 회전, 좌우로 끌기 = 이동, 아래로 끌기 = 천천히 내리기,
    아래로 휙 = 바로 떨어뜨리기
  - 휴대폰은 세로 화면으로 해 주세요. (가로로 눕히면 안내가 나와요)
  - 휴대폰에서 하려면 게임 폴더를 웹에 올려서(https 주소) 링크로 열어야 해요.

■ 카카오톡으로 링크 보내기
  - 카카오톡에서 링크를 누르면 자동으로 Chrome이 새로 열려요.
    (안드로이드: Chrome 앱 / 아이폰: Chrome 앱, 없으면 Safari)
  - 자동으로 안 넘어가면 안내 화면의 [Chrome으로 열기] 버튼을 누르면 돼요.

■ 중국어 음성 (Tingting)
  - Tingting은 Mac·iPhone에 들어 있는 음성이에요.
  - Windows에는 Tingting이 없어서 「Google 普通话」(인터넷 필요) 또는
    Microsoft 중국어 여성 음성이 자동으로 쓰여요.
  - 게임 안 설정 화면에서 음성을 직접 고르고 테스트할 수 있어요.

■ 단어 (HSK 급수별 + 짝꿍어휘)
  - data.js에 HSK 4급 필수 어휘 1000개와 단어마다 짝꿍어휘 3개가 들어 있어요.
  - 5급, 6급은 data5.js, data6.js의 words 칸에 같은 형식으로 단어를 넣으면 로비에서 바로 열려요.
  - 진행 기록과 명예의 전당은 급수마다 따로 저장돼요.
  - 노멀 모드: 번호 순서대로 25단어씩 40구간 (1구간 = 0001~0025)
  - 헬 모드: 100단어씩 10구간 (1구간 = 0001~0100)
  - 구간 단어를 모두 한 번 이상 맞히면 별이 붙어요. (기록은 기기마다 저장)

■ 폴더 구성
  index.html / style.css / script.js / data.js  ← 게임
  sound/  ← 배경음악 (효과음은 코드로 직접 만들어서 파일이 필요 없어요)
  icon/   ← 아이콘 (ico: Windows, icns: Mac, png: 웹)
